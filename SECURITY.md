# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it through GitHub's **private vulnerability reporting**:

1. Go to the [Security tab](https://github.com/arpanvgm/ai-bridge/security) of this repository.
2. Click **Report a vulnerability**.
3. Provide a description and steps to reproduce.

Please **do not** open a public issue for security vulnerabilities.

I will acknowledge your report within 48 hours and work with you to resolve the issue.
